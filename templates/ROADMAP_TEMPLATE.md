## How this roadmap works

Phases run Build → Launch → Traction → Grow → Mature. `PRODUCT_PILOT.md` shows one `← ACTIVE` milestone; this file holds every milestone's detail, the decision log, and what is done. A task is one pull request and carries a `[TICKET]` or `[unpoured]` tag. Ordering is dependency first, then the shortest path to the next external release. Add a scoring framework only when there is traffic to estimate reach from.
